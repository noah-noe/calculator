# Voice-Enabled Calculator

A simple web-based calculator built with **HTML, CSS, and JavaScript**. This project combines basic calculator functionality with voice recognition, with a focus on exploring accessibility for people with visual impairments.

## Features

* 🧮 Basic arithmetic operations
* 🔄 Clear/reset functionality
* 🎤 Voice input for mathematical expressions
* 🇺🇸 English voice recognition
* 🇰🇷 Korean voice recognition
* 🇲🇲 Burmese voice recognition *(currently under development)*
* 📱 Simple and responsive interface
* ♿ Accessibility-focused design

##  Accessibility

One of the main goals of this project is to explore how voice-based interaction can make a calculator more accessible, particularly for **people with visual impairments**.

The current version focuses on voice input, allowing users to speak mathematical expressions instead of relying only on the visual calculator interface.

### Planned Voice Output

A future improvement is to add **voice output** so that the calculator can read the calculated result aloud.

For example:

> 🎤 User: "5 plus 3"

> 🔊 Calculator: "8"

This would allow users to both **speak an expression and hear the result**, making the calculator more accessible for people who may have difficulty viewing the screen.

## Language Support

The calculator is designed to support:

* 🇺🇸 English
* 🇰🇷 Korean
* 🇲🇲 Burmese

### Current Status

English and Korean voice recognition are currently working.

The **Burmese voice recognition feature is currently not working reliably** in my development environment. I am investigating browser and speech-recognition compatibility and plan to improve this feature in a future update.

##  Known Limitations

* Burmese voice recognition is currently inconsistent.
* Voice recognition depends on browser and speech-recognition support.
* Spoken number recognition can vary depending on the browser and language.
* Voice output has not yet been implemented.
